# encoding_specimens

Working sketches from the 2026-08-27 part 3 encoding session. **Not artifacts.**

`bite_points.py` / `.svg` / `.png`
Live. Composites a bite-point annotation layer onto the real `national_baseline.svg`
at the same viewBox. This is the D-58 mapping made visible. Band widths deliberately
not drawn — per-$100 values are blocked on the FY2029 denominator.

`encoding_specimen.py` / `.png`
Partly live. Demonstrates D-49's composition partition (solid federal / open
non-federal, absent on the two exempt slices). The *rule* survives; the flat-bar
presentation does not — see D-54. Figures are in ten-year $B, which is the wrong
currency for the master (per $100). Read for the partition only.

`container_specimen.py` / `.png`
Superseded presentation, live rule. D-52's container encoding: open edge, no fill,
fixed-width crossings. JW's verdict on the drawing itself was that it is ugly and
unclear; the three encoding moves in it are still the decision.

Both specimens predate `reference_renders/design/overlay_grammar_schematic.png` and
were built without it. That is the S-045 failure in artifact form — kept as evidence,
not as guidance.
