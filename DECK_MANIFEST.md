# MHPA board deck — package for the repo

Built 27 September 2026 against `JameyHarvey26/Medicaid-dollar` `main`.
Copy these into the repo root, keeping `deck_alts/` as a directory.

---

## New files

| File | What it is |
|---|---|
| `landing.py` | The project's public URL, declared once. `URL`, `DECK_LINE`, `FOOTER`. Read by both the paper renderer and the deck, so the address exists in one place (D-103). |
| `deckalts.py` | Generates the nine slide figures. Every value is read from `ledger_national_2024`, `ledger_national_2030`, `tobe2030` and `incidence` at import. Renders each figure twice — standalone, and `_bare` with its own header cropped and footnote dropped, for embedding in the deck where the slide carries the title. |
| `build_deck.py` | Assembles `MHPA_Board_Deck.html`. One slide per `h2` in the manuscript, in the manuscript's order. Every figure in the prose is an f-string off the ledger; nothing is typed. Images are embedded base64, so the HTML is self-contained. |
| `deckfit.py` | The deck's stranding gate. Measures every slide in Chromium and reports OVERFLOW (content taller than the fixed box, so something is clipped) and air (figure not filling its frame). Exits non-zero on any overflow. Run after `build_deck.py`. |
| `deck_alts/` | The rendered figures, SVG and PNG, standalone and `_bare`. Regenerated by `deckalts.py`; kept so the deck can be rebuilt without re-rendering. |
| `MHPA_Board_Deck.html` | The deliverable. Self-contained. |
| `MHPA_Board_Deck.pdf` | Chromium print of the same file, 11×8.5in landscape, 13 pages. |

## Build order

```
python3 deckalts.py      # renders deck_alts/, both framings
python3 build_deck.py    # writes MHPA_Board_Deck.html
python3 deckfit.py       # gate: 0 overflows required
```

`build_deck.py` also reads `paper_figs/cover_taper.png` and
`paper_figs/fig6_panel_2030.png`, so `make_figs.py` must have run first.

## Two things worth knowing

**The $10.34 / $10.26 question is settled and needed no correction.** They are
the same money on two denominators. `tobe2030.per100` sums to $10.2592 on its
own denominator; `RESCALE = 1.007619` puts it on the D-70 hundred struck at
the state agency, giving $10.3374 → $10.34. The paper, the taper, the tracker
and the ledger already agreed. Only the diagnostic was misleading.

**`typedfigures.py` cannot see the manuscript.** It scans `.py` files, and
`paper_national_v7_1.html` is hand-authored, so every figure typed into the
prose and the tables sits outside the instrument. The captions reading *read
from the ledger at build time* are not true of the tables.
