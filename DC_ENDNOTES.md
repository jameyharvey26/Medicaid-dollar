# DC endnote register

Numbered endnotes for the District panels. **Every figure that appears on a District artifact has an entry here**, on the same rule as `ENDNOTES.md` (S-054). Generated by `dc_endnotes.py` from the `Fig` records in the ledgers. Do not hand-edit: re-run it.

Numbering is append-only and stable (S-032). The order lives in `DC_ENDNOTE_KEYS.txt` and a DC-EN number is that file's line position. If a figure changes, the entry changes in place and keeps its number.

`DC_PROVENANCE.md` is the narrative companion: it says what was chosen and what is missing, and why. This file keys individual figures to their sources.

Status key: **M** measured · **D** derived from measured inputs · **P** modelled · **C** supplied by the subject · **ABSENT** not published and not estimated.

**No District figure in this project is signed.** `signatures.py` carries no DC entry, so every `Verified` line below reads **no** — including for figures that are measured, correct and uncontroversial. Measured says where a number came from. Verified says a named person opened the source and agreed with it.
