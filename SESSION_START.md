## 1. Get the build up

```
curl -sL https://codeload.github.com/JameyHarvey26/Medicaid-dollar/tar.gz/refs/heads/main
pip install resvg_py pymupdf playwright --break-system-packages
python3 -m playwright install chromium
python3 gates.py                # everything; --quick skips the render gates
```

`gates.py` runs all seven gates and checks each against what it is supposed to
print, which is recorded in `EXPECT` inside that file rather than in prose here.
It enforces the rule that a gate must be shown to have executed and not merely
to have exited zero — a gate that runs clean and prints nothing fails.

**A gate that fails is a finding.** Do not adjust `EXPECT` to make it pass. If
the change was deliberate, update `EXPECT` and record it in the manifest. If it
was not, stop and say so.

404s. `resvg_py`, not cairosvg — cairosvg ignores `paint-order`.

## 4. Verification and signing

`verified` is strict: a person opened the source and agreed with the number. A
redline does not earn it. Signing is a lookup against `signatures.py`, never a
stamp. A figure that has moved since it was agreed is not signed, `check`
reports it LAPSED and the build fails. Correcting a signed figure costs a
deliberate line in the register; that cost is the point.

The order, from `ACQUISITION.md`:

1. Acquire — open the source, name the exhibit, give the vintage, record in the
   publisher's units. Where the source publishes dollars and a share is needed,
   the dollars become anchors and the share derives from them (S-095).
2. Build and render. A green build proves internal consistency and nothing
   more (S-098).
3. Stack the panels — every panel the change touches, before and after, full
   width, one above the other, changed figures named above the sheet. Into
   `reference_renders/`.
4. Look at it. This is the step (S-093).
5. Sign — key and agreed value into `signatures.py` with date and initials of
   whoever looked.

The EN-43 earnings margins stay unsigned on both capitated lanes.

## 5. House rules

Reader first: a time-starved Medicaid executive. Never make them feel stupid or
overwhelmed. Cut anything whose real content is how rigorous we were. State the
positive figure before the decrement. Limits go in footnotes. No rhetorical
flourishes. American spelling. Phases, not columns. Ecosystem, not system. Never
"the Medicaid dollar" in body prose. A plan carries its present-day name with
the former name in parentheses.

Geometry drives arithmetic on the tracker line. Run the detector, not the eye.
Never fill a data gap with a share — absence stays absent and gets declared on
the artifact. Fix the wrong rule rather than clamping the symptom. A published
figure is measured; recomputing it from its parts substitutes our arithmetic for
the source's. Arithmetic adds no confidence to its inputs. Conservation is not
correctness. When a figure is struck as a residual, enumerate what is in it
before giving it a name.

**If the work turns up a figure that is wrong or a label the ledger does not
support, stop and say so. Do not fix it.**

## 6. Working style

Recommend on methodology, ask on direction. Lead with the view and the
reasoning. One question at a time, and wait. Show the picture: any claim about
what a diagram looks like ships with the diagram, or a crop with the thing
circled. When presenting a file, check it is where you say it is.

Write for JW, not for the code. If he says he does not know what you are talking
about, that is a failure of the explanation.

Apply and verify one change at a time. Match across line wrapping. Never abort
the run on one miss. Print a per-edit result. A batch reported as complete is not
proven complete.

## 7. At commit

Session end only, never mid-session. Running manifest as you go.
